# FocusClock 本地重要事务 / 闹钟提醒平台

一个在浏览器本地运行的轻量级「关键任务记录 + 闹钟提醒」小面板，主色调为蓝色 / 白色，并辅以紫色高亮，界面简洁现代、适合长期使用。

> 所有数据都只保存在本机浏览器的 LocalStorage 中，不会上传网络。

## 使用方式

1. 打开文件夹：
2. 双击打开 `index.html`，用你常用的浏览器（建议 Chrome / Edge）打开即可。
3. 首次打开时，浏览器可能会询问「通知权限」，建议允许，这样到点会有系统通知提醒。

## 功能概览

- **快速记录关键事务**
  - 标题、备注、日期、时间
  - 提前提醒（到点 / 提前 5、10、30、60、120 分钟）
  - 事务类别：工作 / 学习 / 生活 / 健康 / 其他
  - 重要程度：普通 / 重要 / 非常重要
- **即将到来的提醒**
  - 展示最近一段时间内的提醒
  - 显示「还剩多少分钟」「预计提醒时间」
- **全部事务列表**
  - 按状态筛选：未完成 / 已完成 / 全部
  - 按类别筛选：工作 / 学习 / 生活 / 健康 / 其他
  - 支持勾选完成、删除、再次提醒（+5 分钟）
- **提醒方式**
  - 页面内弹窗提醒（可在左侧开关中关闭 / 开启）
  - 右下角浮动提示卡片
  - 可选提示音（默认开启）
  - 如允许浏览器通知权限，将同时触发系统通知

## 设计说明

- **视觉**
  - 整体采用深色背景，配合蓝色主色与紫色渐变高光，突出「专注」「冷静」「科技感」。
  - 卡片式布局、圆角、柔和阴影，避免信息密集带来的压迫感。
- **交互**
  - 表单区在左，方便快速录入；即将提醒与任务列表在右侧和下方，形成「输入 → 预览 → 全局」的流程。
  - 所有关键区域都做了轻微的动效反馈（按钮悬停、提交时的微动画）。
